Policy Lifecycle Tool - Help

Overview

This tool documents an insurance policy transaction use case as a succession of transaction lines, each showing policy periods over time.

Main menu

  • Open - load a use case from a .policycase file.
  • Save - save the current use case to a .policycase file using its current name.
  • Save As - save the current use case under a new name.
  • Edit / View toggle - switch between editing and read-only viewing. The tool opens in View mode.
  • Clear - clear the current use case (asks for confirmation).
  • Print - print the current use case using your browser's print dialog.
  • Help - opens this page.
  • About - shows application information.
  • Language selector - switch between English, French, and Spanish.

Use case header

Set a description, start date, time scale (Month or Quarter), range (number of scale units shown), and an 8-color palette used to paint policy periods. Click a color square to change it with your browser's color picker, or drag a color onto a transaction graph to create a new policy period. Use the + button to add a new transaction line.

Transaction lines

Each transaction line has a type (Submission, Policy Change, Cancellation, Reinstatement, Rewrite, Renewal, Comment, Other) and a comment. Use the controls on the left to collapse/expand the line, reorder it (drag the grab handle), edit its properties, or delete it.

Policy periods

Policy periods are rectangles on a transaction's graph. In Edit mode you can:

  • Drag a palette color onto the graph to create a new period.
  • Drag a period to move it.
  • Drag its left or right edge to resize it.
  • Click its edit (pencil) icon to set its policy term/period numbers, description, color, or mark it as a gap.

A gap is shown as a white rectangle with a diagonal cross and only an edit icon.
